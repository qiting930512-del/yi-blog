# 《亞洲，生活：黎明時光》製作路線圖

> 針對一個人、沒有程式背景的開發狀況設計。核心原則：**先做出一個可以走動、可以講話的最小版本，再逐章擴充**，不要一開始就想著把整個遊戲做完。每個階段結束都要有一個「玩得到」的東西，而不是一堆半成品。

---

## 階段 0：學會工具（預估 2–4 週）

在寫任何自己的內容之前，先透過官方教學跟現成的入門課程，熟悉 Unity 的基本操作。目標不是精通，是「知道東西放在哪裡、怎麼讓一個角色走動」。

**建議做的事**：
- Unity 官方的 [Unity Learn](https://learn.unity.com/) 上找 3D 基礎課程（有繁中/英文教學）
- 跟著教學做一個「角色可以用 WASD 走動、鏡頭跟著角色」的最小場景（不用是最終美術，用預設的方塊/膠囊體代替即可）
- 熟悉 Unity 介面：Scene 視窗、Hierarchy、Inspector、Project 視窗這幾個最常用的區域
- 安裝 [Ink](https://www.inklestudios.com/ink/) 跟 [ink-unity-integration](https://github.com/inkle/ink-unity-integration)，跟著它的教學做一個「按互動鍵跳出一段對話」的最小範例

**這階段結束時你會有**：一個空場景，裡面有個方塊可以走動、按鍵可以跳出一段測試對話。不好看，但這是所有後續內容的地基。

---

## 階段 1：序章原型（預估 4–8 週）

把序章（`game-design/scripts/00-prologue-script.md`）做成真正可以玩的一段——這是難度最低、但涵蓋核心機制最多的一章（物品檢查、手機介面、WaWa 翻譯、記憶碎片、移動），很適合當作第一個完整原型。

**建議拆解成的子任務**：
1. 用免費或便宜的資產商店素材（機場場景、簡單的日式住宅外觀）先搭出場景骨架，不用等到有完整美術才開始
2. 做出「物品檢查」的最小互動系統（點擊物件、跳出文字說明）
3. 做出手機 UI 的第一版（黑白線框稿即可，不用精緻）：WaWa、記事本、訊息、健康提醒可點，四個回憶 App 顯示灰階、點了跳出「暫時無法開啟」
4. 把序章劇本轉成 Ink 檔案，串接對話系統
5. 做出「記憶碎片」三層系統裡最簡單的第一層（感官閃回：畫面短暫扭曲 + 文字殘影），先不做過去場景重演（那個留到後面章節，比較複雜）

**這階段結束時你會有**：序章可以從頭玩到尾，玩家能感受到遊戲的核心體驗（雖然美術還很陽春）。

---

## 階段 2：第一章 + 角色互動系統（預估 6–10 週）

第一章（`01-strangers-under-one-roof-script.md`）會逼你做出「跟 NPC 對話」「NPC 有自己的行為/位置」這些後面每一章都要用到的系統。

**建議拆解成的子任務**：
1. 做出基礎 NPC 系統：NPC 可以站在指定位置、被玩家靠近時觸發對話
2. 把陳沐、黎光、張博遠、Leon 四個角色的初登場對話串進 Ink
3. 做出「拍團體照」的簡單互動小遊戲（可以先用最陽春的方式：一個按鈕觸發鏡頭淡出+閃光效果）
4. 開放小型城鎮地圖範圍（先用幾個簡單的場景銜接，不用做滿整座城市）

**這階段結束時你會有**：序章 + 第一章可以連續玩過去，五個角色都登場了。

---

## 階段 3：關係養成 + 記憶碎片核心系統（預估 6–10 週）

這是整個遊戲最關鍵的技術系統，第二章（半開放沙盒）需要它才能運作。建議獨立出來當一個階段，做好之後後面所有章節都能重複使用。

**建議拆解成的子任務**：
1. 設計一個簡單的「關係狀態」資料結構（例如每個角色一個好感度數值 + 一組已解鎖的記憶碎片清單），可以先用 Unity 的 ScriptableObject 或簡單的 C# 類別存
2. 做出關係深化的觸發邏輯：跟某角色做出符合他個性的互動 → 好感度上升 → 達到門檻解鎖記憶碎片
3. 做出記憶碎片第二層（手機記事本的插畫收藏頁面）
4. 做出手機裡「鎖住的回憶 App」逐步解鎖的邏輯

**這階段結束時你會有**：一套可以重複用在第二章到終章的關係/記憶系統骨架。

---

## 階段 4：逐章內容製作（預估：每章 3–6 週，共約 6 個月）

有了前三階段打下的系統骨架，第二章到終章基本上是「重複套用同樣的系統、填入新內容」，速度應該會比前面快。依序製作：

- 第二章：語言學校（沙盒 + 夏祭り + 黎光病倒）
- 第三章：日常裡的裂縫（張博遠/Leon 摩擦事件）
- 第四章：找工作（箱根小旅行、美咲登場、聖誕節）
- 第五章：轉折（陳沐宣布外派，短章節，做起來會比較快）
- 第六章：倒數
- 第七章：送別
- 終章：重新定義家

🔸提案：這個階段可以考慮**先做完第五～七章**（線性、篇幅短、互動精簡），再回頭做第二～四章（沙盒、系統複雜、篇幅重）——先把「情感高潮」做出來，會更有成就感、也更容易判斷整體節奏對不對。但如果想照劇情順序做也完全合理，兩種都可以。

---

## 階段 5：打磨與測試（預估 4–8 週）

- 找幾個朋友試玩，蒐集回饋（尤其注意：沙盒章節會不會太空、記憶碎片解鎖的節奏對不對）
- 修正明顯的 bug、調整節奏
- 補齊音樂、音效（這個文件目前完全沒有規劃到音樂方向，之後可以另外討論）
- 決定發布平台（Steam？itch.io？）跟上架流程

---

## 總覽時程估算

| 階段 | 內容 | 預估時長 |
|------|------|---------|
| 0 | 學會工具 | 2–4 週 |
| 1 | 序章原型 | 4–8 週 |
| 2 | 第一章 + NPC 系統 | 6–10 週 |
| 3 | 關係養成/記憶碎片核心系統 | 6–10 週 |
| 4 | 第二～終章內容製作 | 約 6 個月 |
| 5 | 打磨與測試 | 4–8 週 |

**總計粗估：一個人、業餘時間開發，大約 10–14 個月**（如果是全職投入會快很多，但這個估算是保守抓給業餘/兼職開發用的）。

這只是抓大概的節奏感，不是精確排程——實際做下去一定會有階段比預期快、有階段比預期慢，重點是**每個階段結束都要有一個可以玩的東西**，這樣才不會做到一半失去動力或迷失方向。
